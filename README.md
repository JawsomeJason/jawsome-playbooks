# jawsome-playbooks

This repo moved. The `playbook` command, its packs and its guard hooks now live in [JawsomeJason/jawsome-agents](https://github.com/JawsomeJason/jawsome-agents) as the `playbook` and `claudecode-playbook-guard` plugins, and this repo is archived. Install them with `/plugin marketplace add JawsomeJason/jawsome-agents`, then `/plugin install playbook@jawsome-agents`.
